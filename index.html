Bulk Excel Import → Report Generator
Open Report Generator directly →

1. Paste your Excel data

Select the rows in Excel (include the header row) → Copy → paste directly into the box below, then click Parse Data.

2. Review & Generate

Each row below shows the Segment that will be auto-selected, based on the C/O/F, Script and CE/PE columns. Click Generate Rationale on any row to open the report generator prefilled with that trade's data.

Mapping used: Report Date ← Entry Date · Call Type ← Buy/Sell · Segment ← C/O/F (+ Script for NIFTY/BANKNIFTY/SENSEX → Index Future/Option, + CE/PE for Options) · Script Name ← Script · Buying/Selling Zone ← Entry Zone 1 & 2 (e.g. "137 - 140") · Target ← TRG · Stop Loss ← SL · Expiry ← Expiry (Futures/Commodity/Options) · Strike Price ← Strike Price (Options only).
Note: keep this file in the same folder as report_generator.html — "Generate Rationale" opens it with the row's data pre-filled.
